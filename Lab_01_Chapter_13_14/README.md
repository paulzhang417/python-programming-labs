# Python Programming Lab 01 — Numbers and Variables

**Textbook:** Welcome to CS, Chapters 13–14  
**Software:** Thonny (Python 3)  
**Topics:** `print()`, numeric variables, arithmetic, `//`, `%`, assignment, debugging.

## Student instructions

1. Open Thonny. Choose **File → Open**, then select a `.py` file from this folder.
2. For `exercise_01.py` through `exercise_04.py`, write your program below the comments.
3. For `debug_01.py` and `debug_02.py`, fix the mistakes in the starter code.
4. Run each program with **F5**, check its output, and save with **Ctrl+S**.
5. Keep the required calculations in the program. Do not simply print the expected numbers.
6. Submit all six completed `.py` files as directed by your teacher.

**Note:** The expected output is an example. Minor differences in wording are acceptable if the calculations are correct.
