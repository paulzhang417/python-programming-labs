# Python Programming Lab 06 — Chapter 19: Names for Functions

**Textbook:** Runestone Academy, Welcome to CS, Chapter 19  
**Environment:** Thonny / Python 3  
**Exercises:** 7 (5 Coding, 2 Debugging)  
**Suggested time:** 45–60 minutes

## Learning goals
- Distinguish returning a value from printing a value.
- Define functions with `def`, parameters, and `return`.
- Use returned values in expressions and nested calls.
- Have one function call another.
- Debug code placed after `return` and missing `return` statements.

## Instructions
1. In Thonny, open one `.py` file at a time (File > Open).
2. Read the English comments at the top of the file.
3. For Coding problems, write your own code below the comments.
4. For Debugging problems, correct the supplied code and add the requested comment.
5. Run each file (F5) and compare with the expected output.
6. Save your completed `.py` files with your name in a separate folder.

Do not use `for`, `while`, or `if` in this lab. These concepts come later in the textbook.
